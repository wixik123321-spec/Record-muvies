# AI Shorts RU — анимационные YouTube Shorts с русской озвучкой

Вы вводите **тему**, программа делает готовый вертикальный ролик 1080×1920 на 30–60 секунд:

1. **Сценарий.** Claude пишет историю на русском: сильный хук в первой фразе, нарастание и
   неожиданный финал. Каждое предложение становится отдельной сценой с выбранным визуалом.
2. **Картинка.** Встроенный 2D-движок рисует сцены в плоском стиле. В каждой сцене:
   - один из 13 фонов (ночной город, космос, подводный мир, лес, лаборатория, «мозг» и др.)
     с параллаксом в три слоя;
   - выразительный персонаж с 8 эмоциями и 6 позами: моргает, «дышит», двигает губами
     в такт голосу;
   - 20 анимированных предметов-иконок, крупные надписи и числа, частицы, свечение,
     виньетка и зерно.
3. **Движение и монтаж.** Наезды, отъезды, панорамы и тряска на «бум». Между сценами —
   переходы fade, slide, zoom, flash и whip. Картинка меняется каждые 2–4 секунды.
4. **Озвучка.** По умолчанию Vosk TTS 0.9 (alphacep): 5 голосов, словарь ударений,
   выразительная интонация. Работает офлайн и бесплатно, лицензия Apache 2.0 разрешает
   монетизацию. Голос проходит студийную обработку: срез гула, тёплый низ, «присутствие»,
   де-эссер, компрессор, лёгкая комната. Темп подстраивается под эмоцию сцены, после хука и
   перед развязкой — драматические паузы. Запасные варианты: Piper (легче) и облачный
   ElevenLabs.
5. **Субтитры.** По 1–3 слова, крупный шрифт с обводкой внизу по центру. Звучащее слово
   подсвечивается, ключевые слова выделены отдельным цветом, фраза появляется с анимацией.
   Текст берётся из сценария, поэтому опечаток нет. Время слов считается по фонемам, а
   если есть faster-whisper — уточняется распознаванием.
6. **Звук.** Музыка генерируется под настроение (mystery, epic, calm, tense, upbeat) и
   автоматически приглушается, когда звучит голос. Звуковые эффекты: whoosh, pop, boom,
   riser, ding. Громкость нормализуется до −14 LUFS (стандарт YouTube).
7. **Экспорт.** MP4 (H.264 + AAC, faststart), файл субтитров `.srt` и `.json` с названием,
   описанием и хэштегами. Готовый файл проверяется автоматически.

## Установка

Нужны **Python 3.10+** и **FFmpeg**.

```bash
# FFmpeg: Windows — winget install Gyan.FFmpeg | macOS — brew install ffmpeg | Ubuntu — sudo apt install ffmpeg
cd ai_shorts_ru
python -m venv .venv
source .venv/bin/activate            # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

При первом запуске модель озвучки Vosk (~750 МБ) один раз скачается с alphacephei.com в
`~/.cache/shorts_ru/vosk`. Если она недоступна, программа сама переключится на Piper
(~63 МБ с Hugging Face).

## Ключи API (все необязательные)

Скопируйте `.env.example` в `.env` и заполните только нужные ключи. Программа сама читает
`.env`. Ключи никогда не хранятся в коде.

| Переменная | Для чего | Где получить |
|---|---|---|
| `ANTHROPIC_API_KEY` | сценарий по теме (Claude) | [console.anthropic.com](https://console.anthropic.com) → API Keys. Вместо ключа можно один раз войти через `ant auth login` |
| `OPENAI_API_KEY` | картинки сцен вместо встроенной 2D-графики (`--images openai`) | [platform.openai.com](https://platform.openai.com) → API keys |
| `ELEVENLABS_API_KEY` | облачная озвучка (`voice.provider: elevenlabs` + `elevenlabs_voice_id`) | [elevenlabs.io](https://elevenlabs.io) → Profile → API Keys |

Без ключей работают все режимы, кроме «сценарий по теме»: свой текст, встроенная анимация
и голос Piper.

## Запуск

```bash
# только тема (нужен ANTHROPIC_API_KEY)
python -m shorts_ru "почему мы видим сны"
python -m shorts_ru "загадка Бермудского треугольника" --duration 55 --voice ru_RU-ruslan-medium

# свой текст без ключей: строка или путь к .txt
python -m shorts_ru --text "Знаете ли вы, что… (ваш текст)" --mood mystery

# готовый или отредактированный сценарий (script.json лежит в папке *_work после каждого запуска)
python -m shorts_ru --script examples/octopus.json

# быстро посмотреть стиль: только кадры в заданные секунды, без рендера всего видео
python -m shorts_ru --script examples/octopus.json --preview-frames 1 8 20
```

Результат сохраняется в `output/`:
- `<имя>.mp4` — ролик;
- `<имя>.json` — название, описание, хэштеги;
- `<имя>_work/` — сценарий, озвучка по сценам, `.srt`, аудиомикс.

Основные параметры командной строки:

| Параметр | Значение |
|---|---|
| `-d, --duration` | длительность 30–60 с |
| `--voice` | Vosk: `male_1` (по умолчанию, низкий выразительный), `male_0`, `female_0`, `female_1`, `female_2`; Piper: `ru_RU-dmitri-medium`, `ru_RU-denis-medium`, `ru_RU-ruslan-medium`, `ru_RU-irina-medium` |
| `--mood` | настроение музыки для `--text` |
| `--music file.mp3` | своя музыка вместо сгенерированной |
| `--images openai` | картинки через OpenAI вместо 2D-движка |
| `-c my.yaml` | свой конфиг (можно указать только изменённые ключи) |

## Настройка стиля — `config.yaml`

- **Цвета персонажа**: кожа, волосы, одежда.
- **Субтитры**: шрифт (нужна кириллица), размер, высота, цвета активного и ключевых слов,
  обводка, число слов во фразе.
- **Видео**: длительность, fps, качество.
- **Голос**: скорость, пауза между сценами.
- **Музыка и эффекты**: громкость музыки, глубина приглушения, LUFS.
- **Визуальные эффекты**: зерно, частицы.

## Как устроено

```
shorts_ru/
  cli.py          командная строка, .env, обработка ошибок
  pipeline.py     полный цикл, подгонка длительности, рендер через FFmpeg, проверка файла
  writer.py       сценарий: Claude (структурированный ответ) или свой текст → сцены
  models.py       сцена/сценарий и допустимые значения визуала
  tts.py          Vosk / Piper / ElevenLabs, обработка голоса, паузы, тайминги слов (слоги/фонемы + Whisper)
  captions.py     фразы субтитров, подсветка, анимация появления, .srt
  animator.py     камера, параллакс, персонаж, предметы, частицы, переходы
  audio.py        генерация музыки, эффекты, ducking, громкость
  imagegen.py     OpenAI Images (необязательно)
  art/            фоны, персонаж, иконки
```

**Длительность.** Длина сценария рассчитывается по темпу речи. Если озвучка всё равно
получилась заметно длиннее или короче цели, Piper переозвучивает с другой скоростью
(в пределах 0.85–1.25×).

**Ошибки.** Программа выдаёт понятные сообщения: нет FFmpeg, неверный ключ, отказ модели,
лимит запросов, нет сети, неизвестный голос, пустой текст, длительность вне 30–60 с.
Готовый MP4 проверяется: H.264 1080×1920, AAC и длительность.

## Тесты

```bash
python -m pytest tests -q        # или: python tests/test_pipeline.py
```

Тесты работают без ключей: разбиение текста на сцены, загрузка сценария, совпадение
субтитров с текстом и полный рендер 30-секундного ролика.

## Ограничения

- Встроенная графика — плоская 2D-анимация из векторных фигур. Для более детальных
  иллюстраций подключите OpenAI Images.
- Интонация зависит от пунктуации: восклицательные и вопросительные знаки, запятые и тире
  заметно помогают. Числа лучше писать словами (сценарист Claude делает это сам).
- Сравнение голосов на одной фразе: разборчивость по Whisper одинаковая (CER ≈ 1%), но у
  мужских голосов Vosk разброс интонации около 4 полутонов против 2.4 у Piper dmitri, и голос
  ниже (≈100 Гц против 190 Гц). Поэтому Vosk звучит живее.
- Факты в сценарии стоит проверить перед публикацией.
